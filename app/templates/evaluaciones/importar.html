Contenido que deben cubrir:

Cantidad: 10 preguntas. 

{% raw %}Combina preguntas de selección única y de verdadero/falso, intercalándolas a lo largo del listado sin un patrón fijo (no pongas primero todas las de un tipo).
En las de verdadero/falso, redacta aproximadamente la mitad de las afirmaciones como falsas, y alterna cuál alternativa va primero: en unas "Verdadero" y en otras "Falso".
Idioma: español.

Responde únicamente con el JSON, sin explicaciones ni texto adicional, con esta estructura exacta:

{
  "preguntas": [
    {
      "enunciado": "¿Capital de Chile?",
      "tipo": "opcion_multiple",
      "alternativas": [
        { "texto": "Santiago", "es_correcta": true },
        { "texto": "Lima", "es_correcta": false }
      ]
    },
    {
      "enunciado": "La Luna es una estrella.",
      "tipo": "verdadero_falso",
      "alternativas": [
        { "texto": "Falso", "es_correcta": true },
        { "texto": "Verdadero", "es_correcta": false }
      ]
    }
  ]
}

Reglas del formato:
- "tipo" es "opcion_multiple" (de 2 a 6 alternativas) o "verdadero_falso" (exactamente 2).
- Cada pregunta lleva exactamente UNA alternativa con "es_correcta": true.
- En las verdadero_falso, los textos son "Verdadero" y "Falso".{% endraw %}
Cantidad recomendada: 10 preguntas. Entre 5 y 15 se rinde cómodo en una sesión. Mientras más específico sea el contenido, menos preguntas genéricas devuelve la IA.
